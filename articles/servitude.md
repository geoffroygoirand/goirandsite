# Les servitudes en droit immobilier : définition, règles et recours

Les servitudes constituent une limite au droit de propriété. Elles permettent d'assurer la coexistence entre deux propriétés voisines en conférant au propriétaire d'un terrain certains droits sur un autre terrain.

Qu'il s'agisse d'un droit de passage, d'une servitude de vue, de l'écoulement des eaux ou du passage de réseaux, les servitudes sont strictement encadrées par le **Code civil**.

Avant d'acheter un bien immobilier, de construire ou d'engager un litige avec un voisin, il est donc indispensable de comprendre leur fonctionnement.

## Qu'est-ce qu'une servitude ?

L'**article 637 du Code civil** définit la servitude comme :

> « Une charge imposée sur un héritage pour l'usage et l'utilité d'un héritage appartenant à un autre propriétaire. »

Une servitude met ainsi en relation deux fonds appartenant à des propriétaires différents :

- le **fonds dominant**, qui bénéficie de la servitude ;
- le **fonds servant**, qui supporte la charge.

Contrairement à un droit personnel, la servitude est attachée au bien immobilier. Elle suit donc le terrain lors d'une vente.

L'**article 639 du Code civil** précise que les servitudes peuvent résulter :

- de la situation naturelle des lieux ;
- de la loi ;
- de la convention conclue entre propriétaires.

## Quels sont les différents types de servitudes ?

Le Code civil distingue trois grandes catégories de servitudes.

### Les servitudes naturelles

Les **articles 640 à 648 du Code civil** organisent les servitudes résultant de la configuration naturelle des terrains.

Le cas le plus fréquent concerne l'écoulement naturel des eaux.

Ainsi, le propriétaire situé en contrebas doit recevoir les eaux provenant naturellement du terrain supérieur. En revanche, le propriétaire situé en amont ne peut pas modifier artificiellement les lieux afin d'aggraver cette charge.

### Les servitudes légales

Les servitudes légales sont prévues directement par la loi.

Elles sont principalement régies par les **articles 649 à 685-1 du Code civil**.

Parmi les plus fréquentes figurent :

- la servitude de passage ;
- les règles relatives aux distances de plantation ;
- les servitudes de vue ;
- les règles concernant les égouts des toits ;
- certaines servitudes imposées par des textes spéciaux.

Le propriétaire ne peut généralement pas s'y opposer lorsque les conditions prévues par la loi sont réunies.

### Les servitudes conventionnelles

L'**article 686 du Code civil** autorise les propriétaires à créer librement des servitudes par contrat.

En pratique, ces servitudes sont souvent établies par acte notarié afin d'assurer leur publication au service de la publicité foncière.

Il peut notamment s'agir :

- d'un droit de passage ;
- d'une canalisation ;
- d'un passage de réseaux ;
- d'une interdiction de construire ;
- d'une servitude de stationnement.

## La servitude de passage : quelles sont les conditions ?

La servitude de passage est probablement la servitude la plus connue.

L'**article 682 du Code civil** prévoit que le propriétaire d'un terrain enclavé peut obtenir un passage suffisant sur le terrain voisin afin d'accéder à la voie publique.

Cette servitude n'est toutefois pas gratuite.

Le propriétaire du fonds dominant doit indemniser le propriétaire du fonds servant à hauteur du préjudice subi.

### Où le passage doit-il être établi ?

Selon **l'article 683 du Code civil**, le passage doit être fixé :

- du côté où le trajet est le plus court vers la voie publique ;
- à l'endroit le moins dommageable pour le fonds servant.

Lorsque l'enclave résulte d'une division de propriété, **l'article 684 du Code civil** prévoit que le passage doit, autant que possible, être pris sur les terrains issus de cette division.

Enfin, **l'article 685-1 du Code civil** permet la suppression de la servitude lorsque l'enclave disparaît.

## Comment créer une servitude ?

Une servitude peut être créée de plusieurs manières.

Elle peut résulter :

- d'une disposition légale ;
- d'un contrat ;
- de la destination du père de famille ;
- dans certains cas, de la prescription trentenaire.

Les **articles 690 à 696 du Code civil** distinguent les servitudes pouvant être acquises par prescription.

Seules les servitudes **continues et apparentes** peuvent être acquises après trente années de possession.

À l'inverse, une servitude de passage ne peut pas être acquise par prescription puisqu'il s'agit d'une servitude discontinue.

## Quels sont les droits des propriétaires ?

La servitude ne prive jamais totalement le propriétaire du fonds servant de son droit de propriété.

Toutefois, **l'article 701 du Code civil** interdit au propriétaire du fonds servant de réaliser des travaux qui diminueraient l'usage de la servitude ou la rendraient plus difficile.

De son côté, le propriétaire du fonds dominant ne peut pas non plus aggraver la charge pesant sur le fonds servant.

Les tribunaux apprécient régulièrement ces situations lorsqu'un portail est installé, lorsqu'un chemin est déplacé ou lorsqu'un nouvel usage est donné à la servitude.

## Comment une servitude prend-elle fin ?

Les **articles 703 à 710 du Code civil** prévoient plusieurs causes d'extinction.

Une servitude peut notamment disparaître :

- lorsque son exercice devient impossible (article 703) ;
- lorsque les deux terrains appartiennent au même propriétaire (article 705) ;
- en cas de non-usage pendant trente ans (article 706) ;
- lorsque les conditions prévues par la loi ou par la convention sont réunies.

Chaque situation nécessite une analyse juridique précise.

## Quels sont les litiges les plus fréquents ?

Les conflits relatifs aux servitudes sont nombreux devant les juridictions civiles.

Ils concernent notamment :

- l'existence d'une servitude ;
- l'interprétation d'un acte notarié ;
- la localisation exacte du passage ;
- les modalités d'utilisation ;
- l'aggravation d'une servitude ;
- la demande de suppression de la servitude.

Dans ce type de dossier, l'analyse des titres de propriété, des plans cadastraux et des actes publiés est souvent déterminante.

## FAQ

### Comment savoir si un terrain est grevé d'une servitude ?

Les servitudes peuvent être mentionnées dans l'acte de propriété, dans un acte notarié antérieur ou résulter directement de la loi. Une analyse des titres ainsi que des documents d'urbanisme permet généralement de les identifier.

### Peut-on refuser une servitude de passage ?

Lorsque les conditions de l'article 682 du Code civil sont réunies, le propriétaire du fonds servant ne peut pas refuser le principe du passage. En revanche, il peut discuter de son emplacement ou du montant de l'indemnisation.

### Une servitude disparaît-elle automatiquement ?

Non. Les causes d'extinction sont limitativement prévues par les articles 703 à 710 du Code civil. Une analyse juridique est souvent nécessaire pour déterminer si la servitude existe toujours.

### Peut-on déplacer une servitude ?

Selon les circonstances, un déplacement peut être envisagé à condition de ne pas porter atteinte aux droits du propriétaire du fonds dominant. En cas de désaccord, le juge peut être amené à trancher le litige.
